# Audio Showreel Directory for Afterimage Sound

Drop custom audio files here for Devan's compositions and recordings:

- `film-echoes.mp3` or `.wav`
- `game-descent.mp3` or `.wav`
- `piano-nocturne.mp3` or `.wav`
- `tech-drift.mp3` or `.wav`

The website features an interactive Web Audio synthesizer engine that generates lush ambient motifs by default, and will automatically stream these audio files if their paths are linked in `src/data/tracks.ts`.
